# CivicBallot

## About

CivicBallot is a simple Expo and React Native election voting prototype designed
to make civic participation clear and accessible. It provides a focused mobile
experience for citizens, polling staff, and election administrators.

The current prototype includes:

- Onboarding screens for the CivicBallot experience
- Citizen access using a voter registration number
- Polling unit and ward context
- Party selection for APC, PDP, and ADC
- Ballot submission confirmation
- Initial entry points for election staff and administrators

This project is a prototype for product and workflow development. A
production election system would require independent security review, verified
identity and eligibility checks, ballot secrecy guarantees, auditability, and
compliance with applicable election regulations.

Expo mobile prototype for a civic election voting experience.

## Local setup

Requirements:

- Node.js 18 or newer
- npm, pnpm, or Yarn
- Expo Go on a physical device, or an Android/iOS simulator

Install dependencies and start the app:

```bash
npm install
npm start
```

Then scan the QR code with Expo Go. You can also use:

```bash
npm run android
npm run ios
npm run web
```

The project does not require Replit, a Replit account, or Replit environment variables.
