# CivicBallot

Expo mobile prototype for a civic election voting experience.

## Local setup

Requirements:

- Node.js 18 or newer
- npm, pnpm, or Yarn
- Expo Go on a physical device, or an Android/iOS simulator

Install dependencies and start the app:

```bash
npm install
npm start
```

Then scan the QR code with Expo Go. You can also use:

```bash
npm run android
npm run ios
npm run web
```

The project does not require Replit, a Replit account, or Replit environment variables.
